# 剪映粗剪工程导出

使用已安装的 pyJianYingDraft 与 video-shotcraft 的 Mac 适配模块，把剪辑方案落成剪映草稿。这是本机封装的导出组件，不是完整的自动选材/转写/动画生成系统。

混合可编辑目标从 [4B 入口](../package-talking-head-video/references/hybrid-editable.md) 路由；只有用户明确要求草稿文件才进入本技能的生成分支，不能用新草稿替代当前工程更新。

## 交付约定

- 用户提供真人配音和口语化逐字稿，知识解说为主。单次通常交付 1～3 分钟，用户最终精剪与合并；按本次明确要求调整。
- 原始视频/图片直接入轨，保留原文件与可调整的入出点；不要先把全部画面合成一条底片再切开充当原始粗剪。
- 人声、音乐、音效分别建音频轨；字幕和常改标题使用原生文本。不要把人声、字幕烧进底片。
- 复杂动画可以渲染为独立视频，明确其内部元素不能在剪映逐项修改，保留制作源文件。普通叠加画面尽量独立成轨。
- 为已有工程准备素材时，转用正式媒体文件交付；需要图层细节时读取 图层制作（外部依赖，见仓库 README）。默认用户自己导入，不自动修改当前工程。
- 只交付用户明确要求的草稿文件；不附带预览片、备用素材或原片备份。普通草稿使用原路径引用；只有用户明确要求包含媒体的可携带工程包时才允许复制打包原始媒体。

## 运行环境

本机解释器：`~/.local/share/codex/jianying-roughcut-export/.venv/bin/python`。
使用技能内 `scripts/install_draft.py`，它会接通随依赖安装的 FFmpeg，不修改全局 PATH。
剪映应用已定位为 `/Applications/VideoFusion-macOS.app`（bundle ID `com.lemon.lvpro`），本次维护识别版本为 11.6.13343（2026-10-23），此后按实际安装版本读取；该识别不等于新草稿原生验收。先通过桌面工具观察当前界面。不要因英文文件名误判没有安装剪映。

## 操作范围

普通剪辑交付已检查的媒体文件，由用户导入当前剪映；不调用本技能的新草稿保存或安装流程。

明确要求生成草稿文件时，在工作目录生成必要的草稿数据，镜头引用原始绝对路径，时间以整数微秒表示，使用独立字幕和音轨；参考 [粗剪建轨示例](references/roughcut.md) 的数据结构，不照搬其中打包或验收步骤。仅生成所要求的工程文件，完成结构、媒体依赖与兼容性检查后再交付；没有原生可用依据时不能把 JSON 创建成功称作可用工程。

`scripts/install_draft.py --install` 会复制媒体、安装草稿并涉及退出编辑器；只有用户明确要求媒体打包及入库时才使用。单纯“剪辑”或“生成草稿文件”均不授权此捆绑流程。脚本的预检查模式也不作为默认测试步骤。明确要求打包入库时沿用用户素材路径与指定工程名，不能覆盖正在精修的工程。

完成条件按总规则的文件交付标准：正式文件通过适用检查后交由用户自己导入和放置，不把上轨作为默认完成前提。草稿结构/依赖检查与剪映实际打开验证分别记录；兼容缺口未解决时不交付为可用工程。不主动保存重开、不导出预览、不追加整片验收。
