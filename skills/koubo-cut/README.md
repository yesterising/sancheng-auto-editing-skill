# koubo-cut 口播视频剪辑技能

本机定制版用于当前剪映视频的重点文字、花字和动作配声。执行入口为 [SKILL.md](SKILL.md)，剪辑统一遵循 [视频剪辑总规则](../video-editing-playbook/SKILL.md)。

默认由 Codex 使用已放入剪映的当前视频，第一动作确认用户提供的 SRT；缺失立即提醒，不能先制作或自动转写。正式交付是从 00:00 对齐的完整透明包装，通过文件可用性检查后在 Codex 展示并链接，用户自己导入和拖入剪映；AI 默认不导入或替换。

实际字体按项目锁定，重点默认单行；音效按具体动作选择，不按密度或序号轮换。横屏保留完整口播字幕，竖屏可按总规则精选；主片粗剪、新草稿或导出仅按用户本次明确范围执行。

本机运行路径与脚本边界见 [运行环境](references/local-runtime.md)。build_draft.py 只供明确要求新草稿文件的任务，要求 SRT、已选字体和显式声音事件；不能作为当前工程默认入口。

上游来源：MMACH4/koubo-cut。更新上游时保留本机用户规则，不用旧自动压缩、固定字体或自动配声流程覆盖。
