# 口播全片包装 本机入口

实际执行从 [SKILL.md](SKILL.md) 和 [视频剪辑总规则](../video-editing-playbook/SKILL.md) 开始。默认沿用当前口播与用户 SRT，在本地制作从 00:00 对齐的全片透明包装（4A）；明确要成片、声音、字幕或草稿时才选择对应产物。用户无需记住技能名或逐段指定效果。

先核实 SRT 与最终源时间映射，按语义安排画面和每次 UISFX 选声或留白，复用有效场景与素材。字体、真实证据、人物窗口、竖屏精选与横屏全文规则统一由总规则维护，不按固定左右栏、秒数或结构配额制作。

交付前按 [制作检查](../video-editing-playbook/references/production-checks.md) 核对时间基准、适用兼容依据与静态/动态实际组合；完成 [正式文件检查和统一清单核对](../video-editing-playbook/references/file-delivery.md) 后，仅用成功结果生成的本轮文件链接交付。导入、拖入、替换由用户完成，返修或重做交检查好的新文件链接，旧版保留，导入后不再自动检查。

制作实现、局部检查与缓存分别见技能入口的按需参考；不启动旧版 Gate 审批、不默认生成含原片的整条成片、不自动安装依赖或使用云端。 [旧版 Remotion CLI 资料](references/legacy-remotion-readme.md) 仅供独立明确的旧命令/案例任务，不能覆盖当前默认。
