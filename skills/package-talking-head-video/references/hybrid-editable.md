# 4B 混合可编辑模式

默认 4A 交付已检查的完整透明媒体文件，由用户自己导入和拖到 00:00。用户明确要求混合可编辑、单独改文字/声音或保留可编辑图层时进入 4B；该目标不自动授权 AI 导入、建轨、替换、保存或导出当前工程。

## 制作与路由

先按总规则确认 SRT、工程规格、最终时序与真实字体，每次执行 UISFX 选声或留白及绑定检查。区分 `native_text`、`native_audio` 与 `baked_animation`，记录源路径、对象、全片帧区间、层级和可编辑范围；同一文字/声音不在烘焙层与独立层重复出现。复杂 HyperFrames/Blender 动画保留独立媒体与制作源文件，所有必要媒体从 00:00 同步。

1. **明确要求剪映可编辑草稿文件。** 读取 [草稿技能](../../jianying-roughcut-export/SKILL.md)，在任务目录生成所要求的独立轨道草稿，原媒体引用原路径，不自动安装或退出剪映；只有另有明确要求才复制打包原片。结构、字体、路径、时序和当前版本兼容性均按 [文件交付标准](../../video-editing-playbook/references/file-delivery.md) 验证。尚未确认原生可打开时不能把创建 JSON 成功报成可用工程，也不能默认切换为当前工程写入。
2. **只要求可编辑文件。** 先完成可复用的正式动画、独立音轨，以及真实支持的可导入字幕文件，说明各文件实际能编辑什么。SRT 只承载字幕文字与时序，不声称完整保留艺术字样式和位置。若目标必须用原生工程才可满足，说明当前缺口与可落地产物；不因知道目标工程就改为 AI 建轨，不把清单或源码当成已实现。

本流程仍只交文件，用户自行导入、拖入和替换；原生编辑器操作能力仅供另一个明确的原生操作任务，不作为本流程的自动分支。

## 完成标准

媒体文件逐个通过技术解码、规格、Alpha、内容与兼容路径检查后才交付；原生文件则需适用的结构、依赖与原生可用性证据。准确报告哪些是独立可修改文件、哪些是烘焙画面、是否实际生成可用草稿、是否按另外明确指令操作了原生轨道。只完成清单时报告计划完成；缺失部分不能报为完整交付。

MOV 内部对象是烘焙画面，保留源代码表示可以继续制作修改，不代表在剪映逐项编辑。返修或重做均生成新文件，检查后提供新文件链接，旧文件保留，由用户自己替换；用户导入后不再自动检查。自动局部返修最多两轮，不能以达到轮数为由交付不可用结果。

本机 11.6.13343 的部分原生行为曾在独立工程实测，具体证据见 原生验证与限制（外部依赖，见仓库 README）。该记录不等于新版本、新文件或长口播已经验证，也不授权普通任务建工程、退出、导入或导出；本次字体和布局仍逐项目确认。
