# 12 类动效：从口播语义到剪辑动作

本参考维护本用户的动效选择方法。完整包装的动作设计、B-roll 分镜或相关局部返修读取；仅裁切、仅调音、独立字幕纠错按各自范围执行。执行顺序和交付约束仍由[总规则](../SKILL.md)管理。

## 来源与解释范围


这些条目涉及运动方式、节奏参数、空间组织和信息关系，作为可组合的动效词汇使用。它们补充既有的语义分镜、重点字幕、真实资料展示和人物窗口方法；整张图的卡片布局、蓝紫配色、示例数值不成为本用户的新视觉模板。

## 术语、剪辑用途与实现边界

| 图中类型 | 转成剪辑时解决什么问题 | 执行方式与边界 |
| --- | --- | --- |
| 01 滑动 / Slide & Pan | 同级观点切换、横向比较、步骤推进、长图局部巡视 | 对明确主体做连续位移，保留方向与相邻对象关系；长图移动后停在可读区域。记录位移的是图层、内容视窗还是实际镜头，普通透明层不能驱动底片平移。 |
| 02 信息转场 / Shared Element | 从总览进入某条证据、从缩略图进入详情，帮助观众追踪同一对象 | 让同一张真实图片、同一对象的轮廓/位置/大小跨场景连续变化，并承接到详情阅读态；记录稳定对象身份、起止边界和裁切。对应图中的列表→详情。 |
| 03 缓动 / Easing | 决定入场、落稳、退出和长距离推进的速度感 | 根据动作目的选择：强调入场可先快后慢落稳，退出可逐渐加速离开，连续巡视可平滑启停，匀速过程可用线性。曲线与时长分别记录；缓动用于其他动作，不单独充当语义变化。 |
| 04 视差 / Parallax | 展示前中后景、建立空间深度、引导注意从环境进入主体 | 在已分层素材中让不同深度层产生不同位移或视角响应，确定前后关系与幅度。图中远/中/近景比例只是示意；真实人物或实拍分层须有相应素材/遮罩，单图内部细节没有自动分层。 |
| 05 偏移与延迟 / Stagger | 同一组条目依次出现，降低同时阅读负担，体现顺序或递进 | 记录顺序、各项触发与组内间隔。同一语义事件下的装饰性入场可等间隔；条目跟随不同口播内容时用各自 SRT 事件。首个元素及时可见，最后一项留足阅读时间。 |
| 06 数值变化 / Count Up | 展示已知数值的变化、进度、得分或前后结果 | 明确起值、终值、单位、口径与来源，按帧计算中间状态，终点精确落到目标并稳定停留。只有终值而无增长证据时，计数仅作揭示动画，不暗示真实增长过程；变化量和进度有依据才表达。 |
| 07 父子级 / Hierarchy | 解释总分结构、目录展开、一项任务拆为子项、流程分支 | 用共同来源、空间连接和先后揭示呈现归属；父项先建立，子项围绕对应来源展开。根据实际内容区分从属、步骤和因果，不能仅凭先后出现就画成因果。 |
| 08 叠加 / Overlay | 重点证据浮到前景、局部放大查看、解释层覆盖并返回原场景 | 设计背景/遮罩/前景的层级及出现退出，保留必要上下文；透明度、适量模糊和亮度变化服务焦点。需要模糊或缩小底片时准备实际底片处理，透明覆盖层本身只新增可见内容。 |
| 09 形态转换 / Morphing | 表现同一对象的状态变化、结构转化，例如输入变结果、搜索入口展开 | 给出可见的轮廓或结构过渡，明确前后对象的语义联系。Shared Element 着重追踪对象身份，Morphing 着重形态/状态变化，可组合使用。只有交叉淡化时如实称淡化，不标为已完成变形。 |
| 10 滑动与缩放 / Slide & Scale | 新层进入时旧层后退、从总览进入重点、人物给资料让位 | 统一设计前后层位移、缩放、锚点、裁切和阅读态；图中 100%→98%→95% 仅作空间退让示意。人物窗口变化使用真实同步人物层，底片缩放须有实际处理路径。 |
| 11 克隆 / Cloning | 一份材料分发到多个位置、一套方法复制到多项任务、批量输出 | 保留源对象，生成可追踪的副本并分流到目标，明确副本数量和各自标签。源项消失且只留下单个目标时通常是移动/接续；复制与拆分按内容区分，不用复制画面虚构多个独立证据或真实产出。 |
| 12 维度 / 3D Flip | 同一对象正反面切换、问题揭示答案、表层信息翻到背后解释 | 设置透视、旋转轴、前后面内容及转向，检查侧向经过和背面可读性，避免文字镜像。平面卡片透视翻转可用现有二维/2.5D 路径；需要实体厚度、真实光照或复杂空间遮挡时用适用三维工具，并准确说明实现。 |

## 接入现有制作流程

1. **先确定表达任务。** 继承当前 SRT、事件和素材复用计划，写清“观众需要理解什么→什么对象发生什么变化→落稳后看到什么结果”。稳定阅读或原片人物留白本身适用时保留，不为套术语制造运动。
2. **再选择动作。** 同级切换先考虑滑动；总览到详情考虑 Shared Element；状态/轮廓变化考虑 Morphing；多项递进考虑 Stagger；总分关系考虑 Hierarchy；一到多分发考虑 Cloning；重点前置考虑 Overlay；空间推进考虑 Parallax 或 Slide & Scale；正反面揭示考虑 3D Flip；有依据的数值变化考虑 Count Up。Easing 调整已选动作的速度感。按本片选择必要组合，不设“每片用满 12 类”或效果数量配额。
3. **检查素材与实现能力。** 新视觉继续执行 Pinterest→Cosmos 的实际检索、看图和对照；本图仅作动作词汇参考，不能冒充双站研究已完成。优先沿用 Lemo 适用能力、已有场景与本地组件，需要时用 HyperFrames 或 Blender；图内网页 API 不自动决定实现工具。真实文字、数字、截图与 Logo 使用原资产；涉及原片移动、人物遮挡或窗口变化时，准备实际同步图层。
4. **落实为可定位的动作。** 在现有制作计划中补充下表所列事实，重要动作消费既有 `event_id`。按当前帧率将起止与峰值落到全片帧，先安排结果阅读态，再安排入场和交接。主包装首帧可见要求与竖屏精选留白例外继续按总规则执行。
5. **选择声音并检查正式输出。** 动作明确后仍执行 UISFX，声音峰值对齐接触、落稳、揭示或语义重音；一组交错入场不等于每项都响一次。按本参考下文把实际风险纳入已有局部检查，再沿原流程装配、核对及交付。

## 图中参数如何转成可渲染动作

图里的 300—500ms、50ms 间隔、0.2×/0.5×/1×、0.95 缩放及缓动曲线均是示例起点。按实际画幅、距离、帧率、字量、口播与阅读时间重新决定，不能把图内毫秒直接当本片 SRT 落点。图中缓动坐标与曲线只作设计示意，不作已核验的速度/位移曲线依据。

`translateX`、`clip-path`、`layoutId`、`scrollTop × factor`、`requestAnimationFrame`、`cloneNode`、SVG path、FLIP 与 `rotateY` 是实现提示；使用已有本地工具可表达同一关系。离线渲染将滚动/点击替换为显式时间进度或事件触发，将逐帧累加计数替换为当前帧到数值的直接计算，将克隆身份和起止边界在场景初始化时固定。`requestAnimationFrame` 可作预览调度，正式状态必须由指定时间确定。直接跳到任意帧、反向检查或并行采样时，同一帧应得到同一画面；字体和布局就绪后锁定测量值。

## 并入现有局部检查的项目

按所用动作检查，不额外渲染一套示范片或增加用户审批：1）连续性：Shared Element 的身份及裁切接续，Morphing 的中间态和最终识别，Cloning 的源/副本关系；2）阅读：所有动作落稳后的准确文字、数值、单位、停留和最后一项阅读时间；3）空间：滑动/缩放边缘裁切，视差层露边与遮挡，Overlay 的焦点和底层内容，3D Flip 的侧面闪帧、背面及镜像；4）同步：关键动作实际消费 SRT 事件，数值终点与声音峰值落在当前版本的目标帧。

稳定阅读区间按既有关键帧方法检查；对象交接/变形、快速透视翻转、人物窗口变化、遮罩穿插等高风险动作连续查看正式输出相关短区间及前后衔接，有相关声音时同段合听。任意帧可重建是技术条件，实际连续动作可读是内容条件；按[制作检查](production-checks.md)记录具体观察，沿既有有限返修及最终交付检查执行。
