# 制作检查：时间基准、兼容依据与运动过程

本参考规定实际剪辑中三类判断的完成条件，继承 [总规则](../SKILL.md) 与 [文件交付标准](file-delivery.md)。检查发生在交付前：素材库导入、时间线拖入和替换由用户完成，返修或重做给出已检查的新文件链接，导入后不再自动检查。规则维护、独立素材及仅 SRT 纠错按各自范围执行，不为套用本参考索要无关输入或增加合成验收。

## 先确认 SRT，再锁定最终时间基准

1. **输入门槛。** 第一动作仍是确认用户提供的对应 SRT 存在且可读；缺失、不可读或已明显不匹配时按总规则立即提醒并停止剪辑。通过这一步之后，才读取制作所需的原片、工程规格和已定时序。不能先探查缺 SRT 的工程，也不能自动转写、从工程提取字幕或按稿造时间戳来绕过。
2. **锁定实际版本与映射。** 在本轮记录中绑定实际口播源文件和 SRT 的绝对路径、内容哈希，以及最终工程帧率和总帧数；记录最终项目时间到源片时间的映射，包含片段入出点、删减/换序、速度或变速关系。当前成片第 20 秒不能直接当作原片第 20 秒。一条未经剪切、保持原速的源片可以使用已确认的一一映射，但不能把“没读到剪切信息”当作它的证明。
3. **核对语义锚点。** 首次制作或原片、SRT、主片时序变化后，从开头、中段、末段以及删减、重录、重复语句或变速等易漂移位置选代表性口播锚点，核对实际说话内容、字幕原文与源/项目时刻。锚点数量按本片风险确定，不固定配额；时长接近、文件名相似或开头一句相同不足以确认整片匹配。句级 SRT 不冒称词级精度，需要精细落点时核听对应实际区间。
4. **复用与缺口。** 局部返修可复用哈希、时序与依赖均未失效的匹配证据，只重查受影响位置。重录、主片剪切/速度改变或字幕换版后，旧秒数不能继续直接用于人物窗口、文字或声音。已剪切映射无法读取或与源片/SRT 对不上时，记录具体缺口并停止依赖该映射的装配与可用交付；可继续不依赖它的准备，不猜测同步关系或擅自拉伸字幕。

通过记录须能回答：用的是哪版源片与 SRT，最终时间基准是什么，所选锚点对应哪句、哪个源帧和项目帧，实际观察到了什么。计划里写了映射但未核对实际对应内容，不算匹配检查完成。窗口同步的具体制作继续按 [画中画规则](../../talking-head-pip/SKILL.md)，不另建一套时间线。

## 兼容依据按媒体配置和所用功能判断

记录本轮读取的剪映版本，并把实际交付配置对应到可追溯的实测依据：容器、视频编码及配置/像素格式/位深与 Alpha、尺寸和帧率、音频编码/采样率/声道、色彩/HDR 路径，以及本次依赖的功能。纯音频、字幕或草稿只填写各自适用项目，不用空的视频配置冒充完整检查。证据须列明实测日期、版本、输入配置、实际观察与覆盖范围；可引用 11.6 原生记录（外部依赖，见仓库 README），但不把该案例扩成任意格式或新文件的原生认证。

| 判断 | 条件与后续动作 |
| --- | --- |
| **可沿用适用依据** | 当前产物使用已实测的同类媒体配置和相同功能路径，差异经逐项判断未影响所依赖行为，也没有相反的异常证据。每个正式文件仍须做技术与内容检查；记录为什么这份依据适用。小补丁版本号不同本身不强制重新原生测试，也不自动证明兼容。 |
| **需重新核实相关路径** | 更换容器/编码配置、像素格式/位深/透明路径、音频封装或色彩/HDR；改变草稿结构、字体资源或依赖的原生功能；版本或平台变化涉及本次所用功能；出现黑底、丢透明、音频缺失、打开失败等兼容异常。只核实受影响路径，不默认重测无关功能。 |
| **不得作为可用产物交付** | 本次必要能力无适用证据、已知异常未解决，或所需核实无法完成。可以使用保持用户所需产物和能力的已确认路径；不能将黑底视频代替透明包装，或把普通媒体/JSON 代替用户明确要求的可用草稿。仍不满足则报告缺口，不能标为通过。 |

重新核实先查已有的、对当前配置与功能适用的实际证据，并完成本文件检查；本流程不为核实而代导入、拖入、替换、退出或新建剪映测试工程。需要新的原生验证而当前没有证据时，兼容检查保持未完成，不用文件可解码或历史案例代替。草稿的结构和依赖检查与原生可打开证据分别记录，未确认可打开的草稿不以可用工程交付。沿用证据表示此路径有依据，不表示本轮文件已经在剪映原生打开。

## 静态关键帧与高风险动态连续检查

涉及核心词、重点强调或语义动画时，同时执行 [选词与效果检查](../../koubo-cut/references/core-keywords-and-semantic-emphasis.md)：确认当前定稿与实际文字/动作一致，保留否定、条件及事实边界，核对强调收益、对象关系、主次和真实落点。选词检查在制作前完成，实际效果复查使用下述同版正式合成证据；用户定稿与学习记录放入原计划，不另造运行时字段，也不以用户确认替代内容检查。

先按本次新增/改动范围及依赖给实际区间分类，说明风险依据；不把全片统一标为低风险来减少检查。首次制作覆盖各新增场景，返修只扩到受影响区间。检查同一版正式文件及全部实际图层/声音，复用 [正式输出局部检查](../../package-talking-head-video/references/revision-workflow.md) 的现有证据，不重复启动一套验收。

- **低风险静态/稳定阅读区间：** 查看能覆盖首尾、入场落稳、阅读态和实际极值/切点的必要关键帧，核对真实字形、边界、内容、停留与字幕/人物避让。透明留白和稳定静态字幕按总规则是有效结果，不因缺少运动而返修。
- **高风险动态区间：** 动态人物抠像或人后文字、同步窗口交接/变形、可能截字或遮挡的运动极值、对象接触/穿插/机械因果、快速转场或闪帧风险、声音峰与视觉接触必须准确对应等，须连续查看正式输出中覆盖该动作及前后衔接的有关短区间。不能只用几张 PNG、动画运行页或旧预览代替连续观察后填通过。
- **合成关系与声音：** 按交付层级将原片对应画面与所有正式层合看，核对实际透明区域、全屏覆盖和人物窗口；相关声音与原口播及已有 BGM 同段合听，检查打点、尾音、重叠和口播清楚程度。孤立透明层和孤立音效不能证明最终组合可用。只改画面且未影响声音时，可复用有效声音证据与 UISFX 决策，不无关重听整片。

文字检查落实总规则的大字与描边要求：在实际发布画幅及正常播放、常见手机观看尺度下，检查重点文字是否获得足够画面空间，普通字幕和辅助标签是否可直接读清，轮廓是否清晰且未吞没字腔、细笔画、标点或单位；在实际原片背景与运动极值核对截边、遮挡、对比和阅读停留。文字偏小时先调整可用版面与同屏信息，再按需要改字号/描边；只记录字号参数或只看放大截图不能证明可读。复用上述既有关键帧与相关连续区间，不新增独立审阅流程。

连续查看可直接读取/播放正式文件的相关区间；为检查提取的必要帧、短区间和声音留在 `work/`，保持正式内容与源时间映射，绑定其来源文件哈希。它们是正式输出的检查证据，不是另做一版测试效果、整片测试成片或用户审批片。缺少连续画面或声音读取能力时，对必需项记录 `unavailable`，不能以静态帧、波形或解码成功替代动态/听感通过。

本次采用 [12 类动效](motion-design-vocabulary.md)中的方法时，将其适用检查项并入上述现有区间：对象身份与交接、数值终值及来源、组内顺序和最后一项阅读、运动裁切与层级、翻面背面/镜像、事件及声音落点。只核对本次实际使用的方法，不要求凑齐类别或另建检查协议。

新增、重做及本轮复用视觉的正式输出，同时按 [视觉完成度与代表镜头预演](visual-quality-and-preflight.md) 的默认可见性要求核对画面亮度、主体尺度和适用的工具处理、数据分发、结果汇聚，再核对本期科技视觉方向、图形/材质、动作细节及相邻镜头承接。采用正常播放、常见手机观看尺度和实际合成背景，复用已有关键帧、连续区间与合成证据，具体记录已看清的对象/变化/路径及差距修正；明确问题使用 `issues`，未解决保持未通过。技术检查或前期预演均不能代替当前正式输出的实际观察。

## 写入同一份交付检查记录

制作了新视觉素材或重做视觉方向时，将 [视觉参考制作记录](visual-reference-research.md) 纳入已有制作计划与画面检查：核对当前素材名词、Pinterest 与 Cosmos 的实际检索/看图证据、采用来源、美术规则及本轮正式画面对照观察。复用适用参考或无新增视觉素材时写具体依据；接入不可用、未看图与未解决的美术差距保持真实状态，不用计划、网址清单或技术解码通过代替。对照及修正复用上文关键帧、连续片段和既有限返修，不另做审批片或新增用户选择步骤。

按 [统一交付清单](handoff-manifest.md) 绑定本轮任务/版本、真实制作计划与正式文件。制作计划复用已有的真实场景/草稿/production上下文，保留实际 renderer、源映射和布局，不造空 HTML、虚构字体或假工程来满足检查入口；现有 UISFX 绑定检查在最终核对中复用，具体适配见 [UISFX 参考](../../koubo-cut/references/uisfx-selection.md)。时间安排和 SRT 匹配保留源/项目帧、字幕依据及实际观察锚点；兼容性保留当前/证据版本、配置、变化判断及必要的重核证据；画面记录风险、区间、静态或连续方法，声音记录实际核听区间。每项都引用可读的证据文件及哈希，写具体观察，不只填“通过”。

结果使用 `pass`、`issues` 或 `unavailable` 表达；只在合同明确不适用且有具体原因时使用不适用状态。只有适用的必需检查均完成，才能交给最终核对入口放行；问题或能力缺口按总规则有限返修及停止条件处理。新输出、时间映射或依赖变化后，受影响的观察和兼容判断须重查，不能把旧版通过记录直接贴到本轮新链接上。
