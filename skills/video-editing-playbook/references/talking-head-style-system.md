# 三橙口播动效包装规范

完整口播包装、重做视觉方向及涉及字体、配色、镜头或声音的返修，读取本参考；局部请求只执行受影响项。实际剪辑先通过总规则的 SRT 门槛，规则维护不启动剪辑。固定字体、色彩用途、层级和动作习惯，每一期仍按内容设计分镜。

## 字体、色彩与字幕

以 [EVA Video Style v1.0.0](https://github.com/RoverEva/eva-video-style/releases/tag/v1.0.0) 为默认文字样式。先锁定真实字体文件、字重和字形覆盖，按用途统一全片。ASS 数值以该发布包的设计画布为基准，映射到实际渲染器或剪映后核对字面与位置。

| 用途 | 默认处理 |
| --- | --- |
| 口播字幕 | 中文 Noto Sans CJK SC Black，白字黑边，描边 4、阴影 2。1920×1080 用 52，左右边距各 380、底部 34；1080×1920 用 62，左 110、右 170、底部 440。双语英文用 Inter Bold，浅灰、黑边 3，横 34、竖 38；纯英文用 Inter Black，横 50、竖 64。仅在有双语需求时加英文副行。横屏保留全文，竖屏沿精选规则。 |
| 语义强调字幕 | 沿口播字幕字体、画幅字号和黑边，每条最多一处青柠绿 `#D4FF2E` 高亮。具体选词与时点执行 [语义大字字幕](../../koubo-cut/references/semantic-large-captions.md)。 |
| 开场标题与观点大字 | 英文主视觉用 Anton，Archivo Black 可作备用，横屏展示字以 90–260 px 为参考；中文用 Noto Sans CJK SC Black，按画幅、字数与主视觉区域实测。T21 简洁风格可用 Playfair Display 搭配 Noto Serif CJK SC。需要人物穿插时执行 [人后核心大字](../../koubo-cut/references/large-type-and-occlusion.md)。 |
| 流程标签、数字和截图说明 | 中文用 Noto Sans CJK SC，重点标签用重字重；普通说明及英文用 Inter，版本号、耗时与等宽数据用 Space Mono。标题、标签和说明逐级分配面积；HUD 的 13–16 px 属演示装饰尺度，实质信息按实际画幅放大至手机观看可读。产品名、数字及单位保持精确。 |
| 色彩与容器 | 正文白字和黑边、高亮青柠绿；标题和标签按场景背景选择高对比颜色。界面、Logo、资料及源画面保留本色。容器材质以内部文字和证据清晰为准。 |

### 工作笔记

1. 字体加载完成后，按真实字形、字重、描边及动画外扩测量宽高。放不下时先扩大文字区、沿语义拆成两次出现，或缩小／移动人物窗口，再小幅调字号。
2. 每个镜头先划出脸、口型、关键手势、录屏按钮和证据、平台控件的保护区，再安排字幕与标签。稳定镜头保持字幕位置，遇到遮挡按镜头调整，最后在实际画幅与手机观看尺度核对阅读和遮挡。

## 画面剪辑与分镜

### 先按 SRT 决定谁占主画面

在已有分镜计划里，为每个语义段写清入点、出点、要看懂的一件事、画面素材、人物状态和入场动作。时点来自用户 SRT，精确到按钮点击、口播重音或结果揭晓时再核对原音和录屏。开场可参考 EVA 的 1.5–3 秒构图节拍，在一句话内部也可用揭示、推近或景别变化完成节拍。操作与证据段按真实动作和阅读时间留够时长，长口播按语义段安排起伏。画面切换沿已定原声与主片时间轴执行，删词、变速和重剪按当前授权处理。

| 口播在讲什么 | 画面怎么剪 |
| --- | --- |
| 开场钩子、态度、个人判断 | 先用全屏人物和一条主标题建立焦点；需要强调工具或结果时，可按 T27 用本期真实素材做视频墙，把大字放到人物身后。文字出现后给稳定阅读时间，墙上素材降低对比与细节。 |
| 一项卖点、步骤或对比 | 主标题或结果占一侧，人物用另一侧大圆角窗。两项对比可并列，连续步骤按口播逐项亮起。需要看清具体点击时切实录。 |
| 产品操作、页面、结果或数据证据 | 参考 T19，让真实录屏或截图接管画面，人物退到角落圆窗，或在资料密集段暂时退出。先交代界面位置，再放大当前按钮、输入和结果。等证据读完再切走。 |
| 抽象机制、因果或过程 | 用图解或 B-roll 按口播依次呈现输入、动作与结果。每一拍只加当前要理解的一步；示意画面标明是示意，数字及界面来自可核对素材。 |
| 转折、结论、收尾 | 回到全屏人物或大人物窗，给核心观点和结论一个完整停留。确有对比或揭晓时才加关键动作，结束时保留口播尾音。 |

### 人物窗口和转场连续性

全屏人物用于钩子、态度和结论，大圆角窗用于人物与大字并列，小圆窗用于录屏和图解。横屏可参考 EVA 1920×1080 画布的小圆窗直径 270–340 px，按人脸大小和证据区再测；竖屏重新分配安全区，优先保护口型、下巴、发顶和必要手势。窗的大小、位置、圆角和裁切可以联动变形，下一镜的起始位置接上一镜的结束位置。切换区域要看最终录屏和字幕实际位置，先找稳定空位，确有遮挡再移动。同一个操作段可保持固定角落；鼠标、弹窗或数据变化进入角落时，为证据腾位置。

硬切用在明确的语义切点，滑入用在录屏或新对象接管画面时，遮罩揭示用在前后对比或结果出现时。人物主导镜头可以用 EVA 的 3–6% 慢推作起点，并检查缩放后头部和手势的边界。推近要明确作用于原片、人物还是资料；原片构图变化通过同步人物素材或实际剪辑层实现。人后文字用同源同步前景与动态遮罩，遮挡量以整词可辨认为准。

### 录屏、图形与全片统一

素材优先用本期真实原片、产品录屏、截图、图表和已验证资产。录屏出现时先保证操作对象够大，按真实点击和界面变化做局部放大、框选或标记。需要保留真实操作速度的段落沿源速度使用，放大和框选只改变观看焦点。竖屏宽界面用局部裁切、逐区揭示或全屏细节镜头保住证据尺寸；横屏允许人物与完整界面并列。解释动画用稳定的色彩与图形对应同一对象，数字滚动到有依据的数值，产品名、版本、单位、页面状态保持准确。

按段选择画面风格。工具实录参考 T19，强开场参考 T27，稳定说明段可用 T21 的简洁构图。换风格落在自然语义边界，并延续人物位置、同一标题层级和本期配色。参照 [EVA v1.0.0 发布包](https://github.com/RoverEva/eva-video-style/releases/tag/v1.0.0) 内的 `references/style-guide.md` 与 `references/templates.md`，再按 [动效词汇](motion-design-vocabulary.md) 和本期真实素材确定动作。EVA 的节拍、窗口尺寸和慢推幅度为构图参考，最终按本期原片与目标画幅落实。

## 声音与留白

默认优先给看得见的动作配声，宁少勿多：弹入可考虑短促 tick，甩入可考虑短 whoosh，真实打字过程可考虑键盘声。这些是动作与听感的候选关系，不是关键词到音频文件的固定映射；每次仍须按 [UISFX](../../koubo-cut/references/uisfx-selection.md) 结合具体动作、口播语气及实际素材完成选声或留白记录。

音效听感低于人声，起音、峰值、尾音服务实际入场、接触、揭示或落稳；稳定阅读、停顿与无必要动作的区间优先留白。按实际口播/BGM 合听调整增益，不设跨素材通用的固定分贝值，不为每个关键词加提示声。明确的叙事或情绪需要仍按总规则作具体判断。

## 制作记录与完成判断

将本片字体/资源、色彩用途、字幕规则、各段画面主体、素材及入出点、人物窗口和实际转场、真实人物分层需求及声音理由写入已有制作计划或 `work/design.md`，不新增机器 schema、执行器或用户审批。新视觉继续执行 Pinterest→Cosmos 搜索、实际看图及输出对照；本参考和用户截图不代替双站研究。

把适用项并入已有代表镜头预演和正式输出局部检查：手机尺度下的标题、字幕、按钮及证据可读；窗口连续、脸和手势完整；出入点、点击、结果与口播对齐；录屏停留充分；动态遮罩边缘干净；声音不压人声。复用仍有效的设计与素材；修正后沿原有全片同步、文件可用性及最终交付流程执行，不增加独立整片验收。
