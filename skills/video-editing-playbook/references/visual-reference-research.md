# 按素材名词自主找参考、制作与对照

每次实际剪辑都必须读取并执行本参考，包括首次制作、继续剪辑、局部返修和仅声音/字幕任务：每次先做素材判断，需要新建、重做或改变视觉方向时再执行双站检索与制作。实际口播剪辑先通过 [总规则](../SKILL.md) 的用户 SRT 门槛；独立素材按自身需求执行。整个过程由 agent 自主完成，不要求用户提供参考图、搜索词或逐项选择。当前明确的风格、范围和指定素材优先。

## 明确素材，再搜 Pinterest 和 Cosmos

1. **明确本次素材。** 理解当前口播与镜头目的，提取需要表现的核心名词，并记录它们的动作、关系或结果。例如“AI 助手处理文件”需说明助手、文件如何交互，而不是仅列出机器人和文件图标。每次剪辑先判断本次新增、改造及复用哪些素材；仅裁切、调音、精确字幕纠错等无需新增视觉素材时，记录具体原因，保持本次范围。
2. **生成定向搜索词。** 将核心名词与口播含义、画面用途、全片风格组合，按需要扩展中英文同义词、视觉隐喻和专业设计词。先定全片共同的美术方向，再搜各素材；构图、配色、材质、光影、字体与动作服从同一方向。每个词都机械加“高级、科技感”，不能替代有针对性的检索。
3. **先查 Pinterest，再查 Cosmos MCP。** 对本次待制作的素材主题，实际搜索 Pinterest 并查看候选图，随后调用当前可用的 Cosmos MCP 搜索相关图片/收藏集、按需要找相似图，再实际查看候选图片。两处都查，由 agent 综合筛选；相同名词与风格可合并检索，多个镜头可共享适用参考。使用浏览器、已连接工具或网页图片搜索访问 Pinterest；站外搜索可用 `site:pinterest.com` 定向发现，但仍需打开真实图片。Cosmos 的已核对项目为 [mrmos/cosmos-mcp](https://github.com/mrmos/cosmos-mcp)，按本次实际工具 schema 使用 `cosmos_search`、`cosmos_search_clusters`、`cosmos_similar_elements`、`cosmos_view_images` 等；以当次工具发现和返回为准。
4. **实际看图并筛选。** 用图像内容块、浏览器截图或本地看图工具检查参考；返回网址、文件路径、标题或生成说明不等于已看图。选择能提高本镜头造型、构图、配色、材质或光影的参考，记录具体借鉴点，排除低质、与本片冲突及不适用的候选。动画的动作与节奏需查看真实动态片段；Cosmos 看图工具对视频返回的封面只能用来判断静态设计。

## 将参考落实到制作

制作任何新的视觉素材前，完成上述检索与看图，提炼本镜头可执行的造型、构图、配色、材质与光影规则；动画补充动作目的、焦点转移、节奏及承接。规则应能说明“哪个对象放哪里、做什么、为什么”，而非只写抽象风格词。按任务需要制作内部关键帧后继续实现，不增加逐帧用户审批。

多个素材共享全片风格与实际中文字体约束；根据镜头功能变化景别与强弱。参考用于学习设计规律，原图、Logo、软件界面、数字及能力证据仍采用真实来源与有权使用的资产，不以风格化重绘替代事实。在线参考检索属于选材，不改变既有本地渲染、免费制作和编辑宿主约定。

首次完整包装、新解释动画、风格化 B-roll 或重做视觉方向时，按 [视觉完成度与代表镜头预演](visual-quality-and-preflight.md) 将参考落实为本片设计，先用正式场景代码验证代表镜头的阅读态和连续动作，再批量扩展；仅改字、调音或有效设计复用按实际变化处理。

生成后，将实际画面与选定参考对照，检查主体造型、视觉主次、可读性、材质、光影和统一性；发现明显差距就修正，再查看实际结果。动态差距查看连续片段，不能只凭静态关键帧判断动作。返修沿总规则的最多两轮自动返修及停止条件，问题仍在时记录具体差距，不降低标准或无限循环。优质参考不要求逐像素复制，也不将个人喜好虚构为已通过的用户验收。

## 记录与复用

将素材名词、镜头目的、搜索词、Pinterest/Cosmos 各自实际结果、已查看的来源链接/图片或截图、采用理由、美术规则，以及正式输出对照观察，写入本任务已有制作计划或 `work/visual-references.md`；与当前场景、源/SRT 版本和输出版本对应。只记录实际完成的步骤，不用空表或预填通过代替检索。检查证据并入已有制作检查，不新建用户审批流程。

实际剪辑交付还必须按 [交付记录合同](handoff-manifest.md#每次必有视觉参考检查记录) 填写 `checks.visual_references`，由 `finalize_delivery.py` 核对，缺项/失败不生成可用链接。首次检索用 `researched`；复用用 `reused` 并保留双站原检索、看图证据与本轮对照；没有新增视觉用 `not_required` 并写明原因及空素材列表。工具失败不能冒充无需参考；可以继续不受影响的准备，但相应素材参考未完成时不作为可用成品交付。

局部返修先核对已有参考与本次目的是否仍匹配，复用有效参考及结果；素材或视觉方向变化时，对变更项重新搜索 Pinterest 与 Cosmos。用户已指定精确素材时保留原资产，检索仅用于其展示与周边画面设计，不擅自替换。

## 接入、登录与不可用情况

- **Cosmos 搜图与看图：** 上述第三方 MCP 的文档声明基础搜索、浏览、相似图和看图无需登录；需先在当前客户端配置并启用 MCP。保存收藏、操作个人账户等功能另需登录凭据，这些写操作不属于本流程。无需为搜图先让用户注册、交出 cookie/token 或启用付费模型。服务实际可用性以本轮响应为准，非官方接口可能变化。
- **Pinterest：** 可使用用户已登录的浏览器或可访问的公开页面；出现登录墙、验证码或无法访问时，记录具体情况。确实需要用户完成登录/验证时才提出一次必要操作，账号密码与验证码由用户直接在网站输入。
- **如实降级：** MCP 未配置、网络失败或图片无法查看时，明确哪一步未完成；可用浏览器访问同站或其他公开来源继续不受影响的准备，分别记实际途径。浏览器访问 Cosmos 不冒称 MCP 调用，站外摘要不冒称已查看图片，另一来源成功不冒称两站都已完成。必要参考仍缺失时报告对相应素材的影响，不将其描述为完成参考驱动制作；不反复索要参考图或逐项选择，不默认安装额外服务、付费 API 或上传用户原片。
